# AI = Buffalo

**Working Paper No. 8, Institute for Lexical Equivalence.** Live at https://willardwonder.github.io/AI-Buffalo/

A satirical, interactive "proof" that *AI* and *buffalo* are the same word, built on the real 1972 sentence
[Buffalo buffalo Buffalo buffalo buffalo buffalo Buffalo buffalo](https://en.wikipedia.org/wiki/Buffalo_buffalo_Buffalo_buffalo_buffalo_buffalo_Buffalo_buffalo).

Includes a short playable 3D game (three.js): run a buffalo down a prairie road, collect AI, and choose a side at the fork.

**Controls:** W/S speed, A/D steer, Space jump, Shift sprint, Esc pause, M mute.

The Institute, its studies, journals, authors, and data are fictional. The bison model is from Kenney's Prototype Kit (CC0, see `assets/KENNEY-LICENSE.txt`). three.js is MIT licensed (`vendor/THREE-LICENSE`).
